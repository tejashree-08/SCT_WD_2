# 🚀 Nexus Calc

A modern, futuristic, and responsive calculator web application built using **HTML, CSS, and JavaScript**. Nexus Calc combines elegant UI design with powerful calculation features to deliver a premium user experience.

## 📌 Features

### Basic Operations

* Addition (+)
* Subtraction (-)
* Multiplication (×)
* Division (÷)

### Advanced Functions

* Percentage (%)
* Square Root (√)
* Square (x²)
* Positive/Negative Toggle (±)
* Decimal Support

### Smart Features

* Calculation History
* Real-Time Expression Display
* Copy Result Functionality
* Keyboard Support
* Error Handling
* Responsive Design

### UI/UX Highlights

* Futuristic Glassmorphism Design
* Neon Glow Effects
* Smooth Animations & Transitions
* Dark Theme Interface
* Mobile-Friendly Layout
* Interactive Button Effects

## 🛠️ Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript

No frameworks, libraries, or external dependencies were used.

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/your-username/Nexus-Calc.git
```

2. Open the project folder:

```bash
cd Nexus-Calc
```

3. Launch `index.html` in your browser.

No installation or setup is required.
